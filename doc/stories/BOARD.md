- 2026-10-28: **S-011 done.** ADR 012's mechanism is implemented and tested in `core-services::worker`. API: `PngWorker::new()/with_capacity(n)` (native — dedicated worker thread consuming a bounded `mpsc::sync_channel`, default capacity 4) / `inline()` (synchronous executor; on wasm32 `new()` *is* this — no threads exist on the target). `submit(&ResolvedGrid) -> Result<PngJob, QueueFull>` transfers ownership of the grid over the channel and never blocks beyond enqueue; a full bounded queue yields the typed `QueueFull` (no unbounded growth). `PngJob::poll()` is non-blocking (`try_recv`) for once-per-frame polling: `Pending` → `Done(png)` / `Error(ExportError)`, plus a defensive `Abandoned` (result channel gone — only reachable if the worker thread dies abnormally; pinned directly via a test hook). Drop semantics chosen and pinned: dropping the worker stops *new* submissions but the finite bounded buffer still drains, so queued and in-flight jobs all complete — submitted work is never lost.
